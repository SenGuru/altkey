# drop-in: change two lines

It's the OpenAI SDK. Just point it at altkey.

Same request shapes, same response shapes. Swap your base_url and api_key and ship — works with the Python & Node SDKs, LangChain, or plain curl.

quickstart.py 
from openai import OpenAI

# point the SDK at altkey — that's the whole change
client = OpenAI(
    base_url="https://api.altkey.dev/v1",
    api_key="ak-live-7Qp3xV9rJ2mK8nB4cD6sT1wY",
)

resp = client.chat.completions.create(
    model="gpt-4o",  # or "claude-3-7-sonnet"
    messages=[
        {"role": "user", "content": "Ship it."},
    ],
)

print(resp.choices[0].message.content)
# → runs on YOUR ChatGPT / Claude subscription
