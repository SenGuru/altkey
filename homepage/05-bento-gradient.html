Drop-in

Change two lines — or change nothing.

altkey speaks the OpenAI API. Swap the base URL and key, or turn on zero-config and keep your code exactly as it is.

chat.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://you.altkey.app/v1",
    api_key="ak_live_7Qx9aD2fK4mZ8vN1wPqR",   # your altkey
)

resp = client.chat.completions.create(
    model="gpt-5.5",                # or "claude-opus-4-8"
    messages=[
        {"role": "user", "content": "Explain altkey in one line."}
    ],
)

print(resp.choices[0].message.content)
# → runs on your ChatGPT subscription, not per-token API billing
curl https://you.altkey.app/v1/chat/completions \
  -H "Authorization: Bearer ak_live_7Qx9aD2fK4mZ8vN1wPqR" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      { "role": "user", "content": "Explain altkey in one line." }
    ]
  }'

# Billed to your Claude plan — no per-token API rates.
