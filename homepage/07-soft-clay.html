Drop-in

Change two lines. Keep your code.

altkey speaks the OpenAI API. Swap the base URL and key, and your existing app just works.

example.py 
from openai import OpenAI

# Point the standard SDK at altkey
client = OpenAI(
    base_url="https://api.altkey.dev/v1",
    api_key="ak-live-7Qx9d2Kp...",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user",
         "content": "Explain altkey in one line."},
    ],
)
print(resp.choices[0].message.content)
