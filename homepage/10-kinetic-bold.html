How it works

Three steps from login to API call.

01

Connect your account

Sign in to ChatGPT and/or Claude with OAuth. No passwords pass through altkey — you authorize on the provider's own login page, and you can revoke access whenever you want.

Drop-in code

If it speaks OpenAI, it speaks altkey.

Same SDKs, same request shapes, same response format. Change two lines — the base_url and your key — and your existing code runs on the subscription you already pay for.

app.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.altkey.dev/v1",
    api_key="ak-live-7QxR2m9pK4vN8sLd",
)

stream = client.chat.completions.create(
    model="claude-3-5-sonnet",
    messages=[
        {"role": "user",
         "content": "Summarize this PR in 3 bullets."},
    ],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
request.sh 
curl https://api.altkey.dev/v1/chat/completions \
  -H "Authorization: Bearer ak-live-7QxR2m9pK4vN8sLd" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      { "role": "user", "content": "ping" }
    ]
  }'
