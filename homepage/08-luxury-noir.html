How it works

Three steps. One key. Zero new bills.

No scraping, no extensions, no credentials handed over. Sign in the way you already do, and altkey does the routing.

01

Connect with OAuth

Sign in to ChatGPT and/or Claude through their official OAuth flow. We never see or store your password — just a token you can revoke whenever you like.

02

Get your key

altkey issues one API key and an OpenAI-compatible endpoint. Drop it into any SDK or tool that already speaks the OpenAI format — no code rewrites.

03

Send requests

Call the key from anywhere. altkey proxies each request through your connected account, so usage is billed to the subscription you already pay for.

Drop-in compatible

It's the OpenAI SDK. Just point it at altkey.

Change two lines — the base URL and the key. Everything downstream stays exactly the same.

Python · openai sdk
from openai import OpenAI client = OpenAI( base_url="https://api.altkey.dev/v1", api_key="ak-live-7Qf3X2c9bV1nKpR8sLwZ4t", ) resp = client.chat.completions.create( model="gpt-4o", messages=[ {"role": "user", "content": "Draft a launch note for altkey."}, ], ) print(resp.choices[0].message.content)
Shell · curl
curl https://api.altkey.dev/v1/chat/completions \ -H "Authorization: Bearer ak-live-7Qf3X2c9bV1nKpR8sLwZ4t" \ -H "Content-Type: application/json" \ -d '{ "model": "claude-3-5-sonnet", "messages": [ { "role": "user", "content": "Say hello from my own subscription." } ] }'
